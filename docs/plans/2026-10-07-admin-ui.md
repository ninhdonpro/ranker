# Ranker.vn — Giao diện admin theo design system

## Context

Admin Payload hiện dùng giao diện mặc định: toàn xám, font hệ thống, logo Payload, dashboard chỉ có 5 ô trống, bảng danh sách chỉ có chữ. Đội nội dung thấy "cùi", không mang chất Ranker. Mục tiêu: áp `docs/design.md` lên toàn bộ admin để nhìn hiện đại, chuyên nghiệp và dễ dùng hơn. Không đổi dữ liệu, quyền hay hành vi.

**Quyết định đã chốt (hỏi đáp 07/10/2026):**
- Phạm vi: **theme toàn bộ + logo/trang đăng nhập + dashboard mới + cột danh sách giàu thông tin**. Không override view sửa tài liệu.
- Font: **tự host bằng `next/font`** (Inter, Lora, Barlow Condensed 700).
- **Cả sáng và tối**, ánh xạ bộ token `dark-*` có sẵn.
- **Mật độ gọn cho admin** (input 40px, chữ form 15px, hàng bảng gọn), bổ sung vào design.md để duyệt.

## Kết quả khảo sát

- Payload 3.90 cho tùy biến mà không phải sửa lõi:
  - biến CSS `--theme-*`, `--color-base/success/error/warning-*`, `--font-body`, `--style-radius-*`
  - `admin.components.graphics.Logo/Icon`, `beforeLogin`, `beforeDashboard`, `beforeNavLinks`/`afterNavLinks`, `providers`
  - `admin.meta.icons` (favicon)
  - `admin.components.Cell` cho từng field trong bảng danh sách
  - Dashboard dạng widget (`admin.dashboard`) đang **experimental** → không dùng, dùng `beforeDashboard` (ổn định).
- Hiện có: `src/app/(payload)/custom.scss` (token `--rk-*` cho alert-warning, rk-danger-dialog); `src/admin/translations.ts` (chuỗi `ranker:*`); component custom trong `src/admin/`. `layout.tsx` của `(payload)` do Payload sinh, **không sửa** → font gắn qua `admin.components.providers`.
- Logo trong prototype: ô vuông đỏ `primary` bo `sm` chứa "▲" + chữ "Ranker" + ".vn" màu primary (`prototype/assets/ranker.css:159`).
- design.md viết cho trang công khai, **chưa có pattern admin**: menu bên, bảng dữ liệu, nhãn trạng thái Nháp/Đã đăng/Có thay đổi, thẻ số liệu dashboard, mật độ gọn.
- Lỗi `/admin` → `/admin/users` (404) gặp trong pane là do trình duyệt cache một lệnh chuyển hướng cũ; server trả dashboard đúng (đã kiểm bằng curl và fetch `no-store`). Không phải lỗi app.
